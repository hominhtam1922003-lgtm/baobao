# Dữ liệu nguồn thô (`data-src/`)

Thư mục này chứa 4 bộ dữ liệu mở tải về bởi `tools/fetch_data.py`. Các file nặng bị `.gitignore` để giữ repo nhẹ; chạy lại script để tải:

```powershell
tools\.venv\Scripts\python.exe tools\fetch_data.py
```

Xem URL, giấy phép và số đếm kiểm chứng tại `docs/DATA.md`.
